# Octopus Studio workflow case studies

These examples show how multiple Octopus Studio capabilities can be combined. They are workflow patterns, not promises that every external data source or publishing destination is available without configuring the appropriate model, account, or MCP plugin.

## 1. Research management

**Scenario:** An analyst tracks a market, competitors, and new publications over several weeks.

1. Create a **Chat Project** for the research topic so the work is not tied to a codebase.
2. Save the research method as a reusable **skill**: preferred sources, evidence requirements, citation format, and uncertainty rules.
3. Connect relevant web or knowledge services through **MCP**.
4. Schedule a daily or weekly **task** to gather new material and append a dated summary.
5. Keep working notes in **Markdown**, source tables in **XLSX**, and the stakeholder report in **DOCX**.
6. Use a stronger model for synthesis while Economy Mode handles routine classification and cleanup.

**Result:** Research, source notes, structured data, periodic updates, and the final report stay connected in one workspace.

## 2. Marketing campaign operations

**Scenario:** A small team prepares a product launch without moving constantly between a chat assistant, media folders, and planning tools.

1. Use a Chat Project to define positioning, audience, channels, and the campaign calendar.
2. Search for reference imagery and generate campaign-specific **images**.
3. Preview images, audio, and video assets in the app while refining copy.
4. Draft a campaign brief in **DOCX**, track channel dates and metrics in **XLSX**, and review a **PPTX** launch deck.
5. Connect tools such as a project tracker, content system, or communications service through MCP where available.
6. Schedule recurring tasks for status summaries, content checks, and weekly performance reports.

**Result:** Strategy, assets, deliverables, and recurring coordination live in a repeatable campaign workflow.

## 3. Financial and data management

**Scenario:** An operator receives recurring spreadsheets and needs consistent validation and reporting.

1. Open the source **XLSX** file in the spreadsheet editor and inspect sheets, values, and formulas.
2. Ask the agent to identify anomalies, missing fields, inconsistent categories, and trends.
3. Use an approval-based workflow before applying material edits.
4. Generate a Markdown working summary and a DOCX management report.
5. Schedule a task to repeat the checklist when updated data arrives.
6. Use Economy Mode for formatting/classification and a more capable routed model for deeper analysis.

**Result:** The repeatable data-cleaning process and its narrative outputs remain auditable and easier to rerun.

> Octopus Studio assists with analysis; it does not replace qualified financial, accounting, or compliance review.

## 4. Content creator automation

**Scenario:** A creator turns one research package into several formats.

1. Collect research and outline ideas in a Chat Project.
2. Save voice, style, and fact-check requirements as a skill.
3. Draft the long-form article in Markdown or DOCX.
4. Generate or search for images and preview supporting audio/video assets.
5. Produce derivative briefs for a presentation, newsletter, short video, and social posts.
6. Schedule a task for an editorial review, link check, or recurring content calendar update.
7. Use MCP connections to send approved results to external tools where supported.

**Result:** One evidence base feeds multiple content formats without losing the editorial rules.

## 5. Software development management

**Scenario:** A product lead manages a feature from research to deployment.

1. Use a Chat Project for discovery notes and a coding project for implementation.
2. Produce a blueprint and implementation plan before editing files.
3. Let Agent mode work against the repository while the live HTML/app preview shows progress.
4. Review modified files, tests, logs, and Git commits after each meaningful step.
5. Connect Supabase or Neon for data, GitHub for source control, and Vercel for deployment where appropriate.
6. Schedule changelog, dependency, regression, or stand-up tasks.
7. Use MCP to coordinate issues and project updates in connected tools.

**Result:** Product context, implementation, verification, version history, and delivery form one traceable workflow.

## 6. Client reporting and operations

**Scenario:** A consultant manages multiple clients with recurring research and reporting needs.

1. Create a collection for client projects and a Chat Project for each engagement.
2. Store each client's reporting checklist and tone as a separate skill.
3. Maintain source data in XLSX, working notes in Markdown, reports in DOCX, and review decks in PPTX.
4. Preview supporting media in-app and connect authorized client systems through MCP.
5. Schedule recurring tasks for weekly summaries and monthly report preparation.
6. Keep sensitive accounts separated and review every external action before approval.

**Result:** Each engagement has a reusable structure while its data, permissions, and outputs remain separated.
