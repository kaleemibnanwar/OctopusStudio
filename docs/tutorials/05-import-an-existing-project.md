# Import an existing project

1. On **Home**, select **Import App**.
2. Choose one source:
   - **Local folder** to register or copy a project already on disk.
   - **GitHub repositories** to choose from a connected account.
   - **GitHub URL** to clone a repository directly.
3. Set the project name and, when needed, custom install/start commands such as `pnpm install` and `pnpm dev`.
4. Complete the import and open the project chat.
5. Ask in **Ask** mode for an architecture summary, then use **Agent** or **Plan** for the first change.

An `AI_RULES.md` file can describe the project's stack and development conventions. Never place access tokens in a Git remote URL; use the GitHub integration instead.
