# Connect MCP plugins

Plugins expose external tools through the Model Context Protocol (MCP).

1. Open **Plugins** from the sidebar.
2. Choose a catalog entry or add a server manually.
3. Review the server command/URL, required credentials, and requested access.
4. Complete OAuth or enter the required configuration.
5. Enable the plugin and test it with a narrowly scoped request.
6. Disconnect or remove plugins you no longer trust or use.

Treat plugins like applications with access to your data. Prefer the smallest permissions available, inspect tool calls before approval, and do not connect a production account merely to test a workflow.
