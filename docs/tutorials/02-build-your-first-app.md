# Build your first software project

1. On **Home**, describe the outcome, audience, and must-have behavior. Example: “Build a mobile-friendly reading list with tags, search, and local persistence.”
2. Choose a starter when prompted. React/Vite is a good default; choose Next.js when its framework features matter.
3. Keep the blueprint option enabled if you want to approve scope before files are written.
4. Answer any short questionnaire. Clear constraints produce a more useful first version.
5. Let the agent create files, install dependencies, and start the preview. Approve tools only after checking the requested action.
6. Test the preview, then request one focused revision at a time.

The result is a normal project folder with source files and Git history. Use the changed-files and version views to understand each iteration rather than treating the preview as the only output.
