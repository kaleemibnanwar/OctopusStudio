# Use model routing and Economy Mode

Octopus Studio can use explicitly selected models or automatic routing where available.

## Automatic routing

1. Connect the providers and models you are comfortable using.
2. Open **Settings → AI** and review the router model and automatic model candidates.
3. Choose automatic routing for mixed workloads where the system can select among configured candidates.
4. Choose a specific model when reproducibility, provider location, privacy, or a particular capability matters more than convenience.

## Economy Mode

Enable Economy Mode for routine work where reduced context and output are acceptable—for example classification, formatting, short summaries, or repetitive maintenance. Disable it when a task needs broad project context, long-form output, or deeper reasoning.

Routing and Economy Mode affect model usage; they do not remove the need to review output. Provider availability, cost, and routing options can vary by account and release.
