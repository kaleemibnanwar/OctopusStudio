# Work with documents, data, and media

## Documents and notes

- Open supported **DOCX** files to preview and edit report content.
- Use **Markdown** for research notes, documentation, and portable text workflows.
- Preview supported **HTML** output when reviewing generated pages or reports.

## Spreadsheets and presentations

- Open **XLSX** files in the in-app spreadsheet workspace to review sheets, cells, and formulas.
- Preview **PPTX** presentations alongside their source notes and assets.
- Ask the agent to explain proposed data changes before modifying important workbooks.

## Visual and media files

- Preview supported **SVG** and image assets before using them.
- Review supported **audio** and **video** files in the media workflow.
- Configure image-search providers to find reference or stock imagery.
- Configure media-generation models before requesting new images or video.

Keep an original copy of important business files, especially spreadsheets and presentations. Verify formulas, layout, accessibility, licensing, and factual claims before distributing generated or edited artifacts.
