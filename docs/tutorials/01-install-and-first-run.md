# Install and first run

## Install

1. Open the [latest release](https://github.com/kaleemibnanwar/OctopusStudio/releases/latest).
2. Read the release notes and download the asset for your operating system and architecture.
3. Install or extract the downloaded package, then launch Octopus Studio.

## Finish setup

1. Wait for the Electron window to open.
2. Open **Settings**.
3. Under **Model Providers**, connect a provider.
4. Under **AI**, select the default model.
5. Return home and submit a small test prompt such as “Create a one-page personal reading list.”

If the application does not start, confirm that you downloaded the correct platform/architecture build and check the release notes for known issues. Re-download the asset if the archive or installer appears incomplete.
