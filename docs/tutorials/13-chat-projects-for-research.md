# Use Chat Projects for research

Chat Projects are codeless workspaces for research, notes, plans, and document-oriented work.

1. Create a **New project** and choose **Chat project**.
2. Name it for a durable topic rather than a single question, such as “Renewable energy market research.”
3. State the research question, required evidence, preferred sources, and desired output format.
4. Attach or create supporting Markdown, document, spreadsheet, and media files as needed.
5. Save a reusable skill when the same research method should apply to future work.
6. Create a scheduled task when the topic needs periodic updates.
7. Start a fresh chat or summary when one thread becomes too broad, while keeping it in the same project.

Separate sourced facts, interpretations, and unanswered questions. For legal, medical, financial, or other high-stakes work, require authoritative sources and qualified human review.
