# Preview, inspect, and restore versions

1. Open a coding project and start it from the preview panel.
2. Use the live preview to exercise the current flow. Open console, logs, or tests when behavior differs from the design.
3. Review the modified-files card after an agent turn to see what changed.
4. Open code view when you need the exact implementation rather than the rendered result.
5. Use version history to inspect commits or preview an earlier version.
6. Before reverting, check whether uncommitted or later commits will also be affected; create a branch when preserving an experiment matters.

Octopus Studio uses real Git history. You can continue the same work in another editor or with standard Git commands.
