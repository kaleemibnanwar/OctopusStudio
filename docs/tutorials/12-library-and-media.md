# Use Library assets

The Library keeps reusable and generated resources separate from an individual chat.

- **Prompts:** save useful starting instructions for reuse.
- **Skills:** store procedural instructions loaded when relevant.
- **Themes:** create or edit visual themes used by projects.
- **Media:** search, generate, preview, and organize image/video assets.
- **Templates:** start new coding projects from official, experimental, or community scaffolds.
- **Collections:** group related projects for easier navigation.

To generate media, first configure the image/video model under **Settings → Media Generation**. Generated assets may use a cloud provider depending on the selected model, so avoid including confidential material in prompts.
